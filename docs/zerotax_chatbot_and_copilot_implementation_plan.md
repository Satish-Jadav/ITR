# ZeroTax Intelligent Tax Copilot & Conversational Filing Chatbot: Complete Implementation Plan (API & APK)

This implementation plan addresses the intelligence, architectural, and wiring defects uncovered in the current chatbot across [`Satish-jadav/ITR`](https://github.com/Satish-jadav/ITR) (Android APK) and [`Satish-jadav/ITR-API`](https://github.com/Satish-jadav/ITR-API) (Hono / TypeScript / Supabase Backend). It replaces all hardcoded regex state machines, canned `String.contains()` responses, and disconnected UI states with a **100% Live-Data, Tool-Calling Agentic Tax Copilot** backed by your 14 deterministic Kotlin tax engines and statutory RAG.

## 2. Target Architecture: Hybrid Neuro-Symbolic Agentic Tax Copilot

To make the chatbot genuinely intelligent while guaranteeing **100% accurate tax math and zero mock data**, the new architecture combines **Live LLM Reasoning + Deterministic Tax Engine Tool-Calling + Statutory RAG + Live Vault Context**:

1. **Neuro-Symbolic Separation (LLM Never Guesses Tax Math)**:
   - The LLM (Gemini 2.5 Flash / Pro in [`ITR-API`](https://github.com/Satish-jadav/ITR-API) + Gemini Nano via AI Edge SDK on supported Android devices) handles **natural language understanding, multi-turn conversation, document explanation, and tool selection**.
   - Every rupee calculation is executed strictly by your **14 deterministic Kotlin tax engines** in [`core/tax-engine/`](https://github.com/Satish-Jadav/ITR/tree/master/core/tax-engine/src/main/java/in/zerotax/core/taxengine) (`DeterministicIndianTaxEngine.kt`, `SalaryRestructuringOptimizer.kt`, `ThinkLikeACaDeductionMaximizerEngine.kt`, `RevisionAndHarvestingEngine.kt`, `FnOTradingAndTaxAuditEngine.kt`, `PropertyLtcgIndexationEngine.kt`, `Section143_1IntimationDiffAnalyzer.kt`, `ScheduleFaCalendarYearEngine.kt`). The LLM receives the exact deterministic output and explains it clearly.
2. **Privacy-Scrubbed Live Vault Context Injection (`TaxpayerAnonymizedSnapshot`)**:
   - On every chat turn, [`ZeroTaxViewModel.kt`](https://github.com/Satish-Jadav/ITR/blob/master/app/src/main/java/in/zerotax/app/viewmodel/ZeroTaxViewModel.kt) reads the user's live state from [ZeroTaxVaultDatabase.kt](https://www.google.com/search?q=https://github.com/Satish-Jadav/ITR/blob/master/core/database/src/main/java/in/zerotax/core/database/ZeroTaxVaultDatabase.kt), strips all PII (PAN, Aadhaar, Name, Employer Name, Account Numbers) using `UidaiAadhaarVerhoeffScrubber` and [scrubVerhoeffAndPan](https://www.google.com/search?q=https://github.com/Satish-Jadav/ITR-API/blob/master/src/security/verhoeffScrubber.ts), and attaches a compact JSON snapshot of the user's actual numbers (age group, active regime, selected ITR form, gross salary, claimed 80C/80D/80CCD, remaining deduction headroom, capital gains, AIS mismatches, and tax payable/refundable).
   - Because the bot sees the user's live numbers, it never asks *"What is your salary?"* if Form 16 or AIS was already scanned—it immediately says: *"Based on your scanned Form 16 (₹18.4L gross salary), you still have ₹42,000 of unused 80C room and ₹50,000 of 80CCD(1B) NPS room under the Old Regime, though the New Regime currently saves you ₹14,560 more."*
3. **Statutory RAG (Retrieval-Augmented Generation) over Income Tax Act & CBDT Circulars**:
   - Replace the 3 hardcoded `String.contains()` checks in [`OnDeviceTaxCopilot.kt`](https://github.com/Satish-Jadav/ITR/blob/master/feature/ai-extractor/src/main/java/in/zerotax/feature/aiextractor/OnDeviceTaxCopilot.kt) with a live Supabase `pgvector` knowledge base (`statutory_rag_knowledge_chunks`) indexing all sections of the Income Tax Act 1961, Finance Act amendments, CBDT Circulars, and DTAA treaties. Every bot explanation includes verified section citations (e.g., `[Sec 87A]`, `[Sec 112A]`, `[Sec 44ADA]`, `[Sec 143(1)(a)]`).
